# Projects

Each active project gets its own folder here: `1 - Projects/<Project Name>/`, containing that project's own `Council Sessions/`, `Content/`, `Leads/`, and `Research/` subfolders. This is where project-specific agent output lives — separate from the cross-project `2 - Areas` and `3 - Resources` folders, which are for things not tied to one project (general marketing knowledge, shared research, graphify graphs).

When a project finishes, move its whole folder to [[4 - Archives/_Archives|Archives]] unchanged.
